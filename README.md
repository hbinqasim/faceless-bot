# AI YouTube Automation Pipeline

An AI-powered content creation pipeline that automates the production and publishing of YouTube Shorts.

## Features

- AI Research Agent
- Fact Checking
- Script Generation
- Storyboard Generation
- Image Prompt Engineering
- AI Image Generation
- Animation Pipeline
- AI Voice Narration
- Thumbnail Generation
- Metadata Generation
- Automatic YouTube Upload

## Tech Stack

- Python
- OpenAI API
- Google Gemini
- ComfyUI
- REST APIs
- FFmpeg
- SQLite
- Google OAuth
- YouTube Data API
